# Curved profile imagery — version 2

All eleven profiles were regenerated using the built-in image generation tool. The final images are 1536 × 1024 WebP files in `public/profiles/v2/`. The site uses this version; the first set remains in `public/profiles/`.

The exact prompts, corrective edits, original generated paths, and visual checks are recorded in [profile-v2-prompts.json](profile-v2-prompts.json).

The renders illustrate the defining cross-section features and a smooth radius along the length. They are not dimensioned fabrication drawings. The two custom sloped framing examples follow the unequal-leg concept in the user's original catalog screenshots; the customer's approved section drawing determines the final profile, slope, material, and dimensions.
